About MCP Servers Directory

MCP Servers Directory is an independent, hand-curated catalog of Model Context Protocol (MCP) servers. MCP is the open standard that lets AI assistants such as Claude Desktop, ChatGPT and Gemini securely connect to external tools and data. This site exists to answer one question well: which MCP server do I need, and where do I get it?

How servers are curated

Every listing is reviewed by hand. We favor servers that are actively maintained, officially published by the vendor behind the product, or widely adopted by the community. Each entry carries a plain-English description, a category, keyword tags and a link to its repository, so you can evaluate it in seconds. New servers are researched and added every week.

Submit your server

Submissions are free during launch. Open a GitHub issue with your server name, one-line description, category and repository link via the submission issue button on the homepage. Featured placements are clearly labeled if sponsorship ever opens.
