What is MCP? The Model Context Protocol is the open standard that lets AI assistants (Claude, ChatGPT, Gemini, Cursor…) securely connect to external tools and data. This directory catalogs the servers that make those connections possible — browse by category, or submit your own.

Submit your MCP server — listing is free during launch. Open a GitHub issue with your server name, one-line description, category and repository link: Open submission issue
