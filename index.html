MCP Servers FAQ

What is an MCP server?

An MCP server is a program that exposes tools, resources and prompts to AI applications over the Model Context Protocol (MCP). It lets assistants like Claude Desktop, ChatGPT and Cursor safely read files, call APIs and use external services during a conversation.

What is the Model Context Protocol (MCP)?

MCP is an open standard, originally introduced by Anthropic, that standardizes how AI applications connect to external tools and data sources. Any MCP-compatible client can talk to any MCP server, so a server built once works across many AI apps.

How do I connect an MCP server to Claude Desktop?

Install Node.js, open Claude Desktop and go to Settings → Developer → Edit Config, then add an entry under mcpServers in claude_desktop_config.json that points to the server's command. Every server page in this directory includes a step-by-step how-to and a config example.

Are the MCP servers in this directory free?

All servers listed here are open source and free to use. Some require an API key from the underlying service (for example Brave Search or Stripe), and those services may have their own pricing.

How many MCP servers are listed here?

The directory currently curates 30+ open-source MCP servers across 8 categories — developer tools, productivity, data, web search, communication, finance, AI/agents and files — and new servers are added every week.

How do I submit a new MCP server?

Submissions are free during launch. Open a GitHub issue with your server name, one-line description, category and repository link using the submit button on the homepage.
