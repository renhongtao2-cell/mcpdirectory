How to connect AI Tools Directory to Claude Desktop

  1. This is a remote MCP server — there is nothing to install.
  2. Open Claude Desktop, go to Settings → Developer → Edit Config, and open claude_desktop_config.json.
  3. Add an mcpServers entry pointing at the endpoint URL (see the example below).
  4. No API key is required — the endpoint is public and answers MCP initialize over Streamable HTTP.
  5. Restart Claude Desktop — the server's tools (search, list_industries, browse_industry, get_tool) appear under the tools (hammer) icon in a new chat.
{ "mcpServers": { "ai-tools-directory": { "url": "https://ai-tools-mcp.toolboxes.top/mcp" } } }

The same URL can be added to any MCP-compatible client (Cursor, ChatGPT, Claude Code, etc.). The endpoint follows the Streamable HTTP transport and requires no authentication.

What the tools do

Four read-only tools over MCP:

  • search_tools — keyword search with industry / use-case / department / pricing-tier filters; multi-token AND matching.
  • list_industries — enumerate the 21 industries covered (e.g. marketing, legal, education).
  • browse_industry — list all tools in a given industry, paginated.
  • get_tool — full detail for one tool (description, pricing, features, use cases).
